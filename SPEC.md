# fin-pit indicator conformance, spec 1.0

This spec defines a small set of golden vectors for technical indicators, with **named variants**
for the places where libraries make different, defensible choices. A library declares the variant
it implements and is checked against that variant. A difference that matches a declared variant is
not a failure; it is a documented choice.

The vectors ship inside the `fin-pit` package (`fin_pit/conformance/vectors/vectors.json.gz`, plain
JSON after gunzip) and are generated by `tools/gen_vectors.py` from the reference functions in
`fin_pit/conformance/reference.py`.

## Document format

```
{
  "spec": "fin-pit indicator conformance",
  "spec_version": "1.0",
  "global_axes": {"warmup": ["nan", "partial"], "zero_division": ["talib", "nan"]},
  "indicators": {"<name>": {"title", "inputs", "params", "outputs", "axes", "talib"}},
  "fixtures": {"<fixture>": {"description", "data": {"open", "high", "low", "close", "volume"}}},
  "cases": [
    {
      "id": "rsi/smoothing=wilder/walk_a",
      "indicator": "rsi", "params": {"length": 14}, "variant": {"smoothing": "wilder"},
      "fixture": "walk_a",
      "first_valid": {"rsi": 14},
      "expected": {"rsi": [null, ..., 52.3, ...]},
      "zero_div": {"rsi": [14, 15]}
    }
  ]
}
```

- `expected` holds one list per output, aligned with the fixture's bars. `null` is NaN and appears
  only in warmup positions (before `first_valid`).
- `zero_div` lists, per output, the positions whose canonical value came from a zero denominator
  (0/0 or x/0), found by running the reference twice. Empty lists are omitted.
- Every combination of an indicator's variant axes is present for every fixture.

## Fixtures

| Fixture | Bars | What it exercises |
|---|---|---|
| `walk_a` | 260 | random walk, 1.5% daily volatility |
| `walk_b` | 260 | random walk, 3.5% daily volatility |
| `trend_up` | 120 | straight line up (oscillators pinned at extremes) |
| `trend_down` | 120 | geometric decline |
| `flat` | 60 | constant price, zero range, constant volume (every 0/0 case) |
| `zigzag` | 100 | alternating 99/101 |
| `shock` | 150 | 30% gap down at bar 75 with a 20x volume spike |
| `short` | 12 | shorter than most warmups (all-NaN outputs are the expected answer) |

The series come from a 64-bit linear congruential generator in `tools/gen_vectors.py`, rounded to
4 decimals, so the file is reproducible byte for byte.

## Comparison

A value `a` matches the expected value `e` when `|a - e| <= atol + rtol * |e|`, with
`rtol = atol = 1e-9` by default. Two global axes apply to every indicator:

| Axis | Option | Meaning |
|---|---|---|
| `warmup` | **nan** | every position before `first_valid` must be NaN |
| | partial | positions before `first_valid` are not compared (a library that computes over the bars it has, as stockstats does with `min_periods=1`, declares this) |
| `zero_division` | **talib** | the canonical value at 0/0 positions: 0, or 50 for RSI (TA-Lib 0.8.3) |
| | nan | NaN is accepted at the positions listed in `zero_div` |
| | a number | that number is accepted at the positions listed in `zero_div` (pandas-ta returns 0.0 for a flat RSI) |

An expected finite value matched by NaN is a failure, except under `zero_division=nan` at a
`zero_div` position. An infinite value is always a failure.

## Definitions

Notation: `x` is the input series, `n` the length, `i` the bar index. "SMA seed" means the first
value of a recursive average is the mean of its first `n` inputs, placed at the last of them.

- **sma**: mean of the last `n` closes. First value at `n - 1`.
- **ema**: `e[i] = e[i-1] + a * (x[i] - e[i-1])`, `a = 2/(n+1)`. `seed=sma`: SMA seed (TA-Lib,
  pandas-ta). `seed=first`: `e[0] = x[0]` (pandas `ewm(adjust=False)`). `seed=adjusted`: pandas
  `ewm(span=n, adjust=True)`, the weighted mean with weights `(1-a)^k` over all bars so far
  (stockstats). Positions before `n - 1` are warmup in every variant.
- **wma**: weights `1..n`, newest heaviest.
- **dema / tema**: `2E1 - E2` and `3E1 - 3E2 + E3`, where `Ek` is the EMA of `E(k-1)`. `seed=sma`
  seeds each stage on its own first full window (warmup `2(n-1)`, `3(n-1)`); `seed=adjusted` uses
  adjusted EMAs from the first bar.
- **trima**: SMA of an SMA with lengths `(n+1)/2` twice for odd `n`, `n/2` then `n/2 + 1` for even `n`.
- **kama**: efficiency ratio `|x[i] - x[i-n]| / sum |x[k] - x[k-1]|` over the last `n` changes,
  `sc = (er * (2/(fast+1) - 2/(slow+1)) + 2/(slow+1))^2`. `seed=close`: seeded with `x[n-1]`
  (TA-Lib, pandas-ta); `seed=sma`: seeded with the SMA of the first `n` closes (StockCharts,
  stockstats). `start=talib`: first value at `n`; `start=pandas_ta`: the seed itself is emitted
  at `n - 1`.
- **hma**: `WMA(2 * WMA(x, floor(n/2)) - WMA(x, n), floor(sqrt(n)))`.
- **vwma**: `sum(close * volume) / sum(volume)` over `n` bars.
- **midpoint / midprice**: `(max + min) / 2` of the close, or of high and low.
- **bbands**: middle = SMA, upper/lower = middle +/- `std` standard deviations over `n` bars with
  `ddof` 0 (population, TA-Lib) or 1 (sample).
- **rsi**: average gain / (average gain + average loss) * 100 over price changes.
  `smoothing=wilder`: Wilder average (`a = 1/n`, SMA seed over the first `n` changes; first value
  at `n`); `ema`: `a = 2/(n+1)` with SMA seed; `sma`: plain mean of the last `n` changes (Cutler);
  `wilder_adjusted`: pandas `ewm(alpha=1/n, adjust=True)` over the changes (stockstats).
- **cmo**: `100 * (gains - losses) / (gains + losses)`; `smoothing=wilder` (TA-Lib) or `sum` over
  the last `n` changes (the original definition, pandas-ta).
- **mom / roc**: `x[i] - x[i-n]` and `100 * (x[i] / x[i-n] - 1)`.
- **macd**: line = EMA(fast) - EMA(slow), signal = EMA(signal) of the line, hist = line - signal.
  `seed=talib`: the fast EMA is seeded on the `fast` closes ending at `slow - 1`, so both EMAs start
  together; `independent`: each EMA SMA-seeded on its own first window (pandas-ta);
  `adjusted`: adjusted EMAs from the first bar (stockstats). `align=all`: every output starts at
  `slow + signal - 2` (TA-Lib); `align=each`: the line starts at `slow - 1` (pandas-ta).
- **apo / ppo**: `MA(fast) - MA(slow)`, and that divided by `MA(slow)` times 100; `ma=ema` (TA-Lib
  0.8.3 default, `matype=1`) or `sma` (pandas-ta).
- **trix**: `100 * (E3[i] / E3[i-1] - 1)` of the triple EMA; `seed` as for tema.
- **willr**: `-100 * (highest high - close) / (highest high - lowest low)` over `n` bars.
- **cci**: `(tp - SMA(tp)) / (0.015 * mean absolute deviation)`, `tp = (h + l + c) / 3`.
- **stoch / stochf**: %K = `100 * (c - lowest low) / (highest high - lowest low)` over `fastk`;
  slow %K = SMA(%K, slowk), %D = SMA(slow %K, slowd) (or SMA(%K, fastd) for stochf).
  `align=all` (TA-Lib) starts %K with %D; `align=each` (pandas-ta) starts each as soon as it exists.
- **ultosc**: weighted 4:2:1 average of buying pressure / true range sums over 7, 14, 28 bars.
- **aroon / aroonosc**: `100 * (n - bars since the highest high / lowest low) / n` over `n + 1`
  bars, ties to the most recent bar; oscillator = up - down.
- **bop**: `(close - open) / (high - low)`.
- **mfi**: money flow index, positive / (positive + negative) money flow * 100 over `n` bars.
- **plus_di / minus_di / dx / adx**: Wilder directional movement. Sums of +DM, -DM and TR are
  seeded over the first `n - 1` changes and updated `s = s - s/n + today`; DI = `100 * DM / TR`;
  DX = `100 * |DI+ - DI-| / (DI+ + DI-)`; ADX = Wilder average of DX seeded with the mean of the
  first `n` DX values (first value at `2n - 1`).
- **trange**: `max(h - l, |h - c[i-1]|, |l - c[i-1]|)`, from bar 1.
- **atr**: `smoothing=wilder` (TA-Lib, pandas-ta), `sma`, `ema`, or `wilder_adjusted` (stockstats:
  the first bar's true range is `h - l`, then `ewm(alpha=1/n, adjust=True)`). **natr** = `100 * ATR / close`.
- **stddev / var**: rolling standard deviation and variance with `ddof` 0 or 1.
- **obv**: running volume signed by the close's direction; `start=volume` begins at the first
  bar's volume (TA-Lib, pandas-ta), `start=zero` at 0 (stockstats).
- **ad**: running sum of `((c - l) - (h - c)) / (h - l) * volume`. **adosc**: EMA(fast) - EMA(slow)
  of the A/D line, both started at its first value (TA-Lib), first output at `slow - 1`.
- **linearreg / linearreg_slope**: least-squares line over the last `n` bars; its value at the
  newest bar, and its slope.

## Versioning

`spec_version` changes when a definition, fixture or comparison rule changes. New indicators or
variants are added in a minor version (1.1); a changed expected value for an existing case is a
major version (2.0). `tools/gen_vectors.py --check` runs in CI so the file never drifts from the
reference code.
